# Image Gallery

A responsive image gallery web application featuring beautiful nature images with an interactive enlarged preview.

## Features
- Responsive image grid layout
- 8 images in the gallery
- Clickable images
- Enlarged image preview (lightbox)
- Close button to exit the preview
- Click outside the image to close the preview
- Responsive design for mobile and desktop
- Alt text for images

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Open the Image Gallery.
2. Browse the images displayed in the grid.
3. Click any image to view it in a larger size.
4. Click the close button or outside the image to exit the preview.
